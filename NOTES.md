# Project Notes

## Project Summary
Global Market Hub is a financial dashboard featuring 21 markets: Equities, Bonds, FX, Derivatives, Real Estate, Insurance, Commodities, Global Macro, Equity+, Crypto, Credit, Sentiment, Calendar, Alerts, Watchlist, Analytics, IMF, World Bank, BLS, EIA, and Census. It utilizes a centralized DataProvider pipeline with an on-demand fetch architecture and bento-grid dashboards for all views. The system ensures full transparency via a DataFooter/MetricValue provenance system for every data point.
